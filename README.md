### 🦀 Sistema Acadêmico — Rust

Aplicação de terminal desenvolvida em Rust para controle de notas e acompanhamento do desempenho acadêmico.

**Tecnologias:** Rust e biblioteca padrão da linguagem.

**Funcionalidades:**
- Cadastro de múltiplos alunos
- Registro e validação de três notas
- Cálculo automático de médias
- Classificação de aprovados e reprovados
- Relatório geral da turma
- Tratamento de entradas inválidas

**Conceitos aplicados:** `for`, `loop`, `match`, `if/else`, funções, tipagem estática e tratamento de resultados.
